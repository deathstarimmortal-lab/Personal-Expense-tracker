# Project Statement

## Problem Statement
A student usually makes small day-to-day purchases but may fail to keep track of where his/her money is going. The calculation of total and category-wise expense may prove difficult manually.

The Personal Expense Tracker helps tackle the above problem by means of a basic Python console program. A user is able to input expenses, look through them, change or delete a certain entry and calculate some information about the expenses.

## Scope
The project includes the following features:
- Recording of personal expenses.
- Reading and editing of expenses.
- Calculation of the number of expenses and amount of spending.
- Category-wise calculations.
- Comparison of category-wise spending with the budget entered by a user.
- Illustration of basic algorithms listed in the course syllabus.

The project does not involve database, web application, mobile application, log-in mechanism and machine learning.

## Target Users
- College students.
- New users requiring easy personal expenditure tracking.
- Users requiring easy expenditure summaries.

## Features at a High Level
1. CRUD operations for expenses.
2. Expense reports.
3. Budgeting and categorization analysis.
4. Validation of inputs.
5. Algorithm demonstrations.

## Scope within Academics
The project is purposefully developed using beginner concepts in Python taught in class. It makes use of functions, lists, tuples, sets, dictionaries, conditional statements, looping statements, and basic algorithms.
